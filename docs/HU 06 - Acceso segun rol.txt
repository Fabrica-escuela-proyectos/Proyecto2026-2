Feature: HU-06 Acceso según rol
  Como usuario de la plataforma
  Quiero acceder solo a las funcionalidades definidas para mi rol
  Para que cada persona use únicamente lo que le corresponde

  Scenario: Cliente gestiona sus propias reservas y datos
    Given un usuario con rol "Cliente" ha iniciado sesión
    When intenta gestionar una reserva o dato que le pertenece
    Then el sistema permite la operación

  Scenario: Cliente intenta gestionar reservas o datos de otro usuario
    Given un usuario con rol "Cliente" ha iniciado sesión
    When intenta gestionar una reserva o dato que no le pertenece
    Then el sistema deniega el acceso

  Scenario: Proveedor gestiona los recursos de su propio negocio
    Given un usuario con rol "Proveedor" ha iniciado sesión
    When intenta gestionar servicios, horarios, recursos o reservas de su propio negocio
    Then el sistema permite la operación

  Scenario: Proveedor intenta gestionar recursos de otro negocio
    Given un usuario con rol "Proveedor" ha iniciado sesión
    When intenta gestionar servicios, horarios, recursos o reservas de otro proveedor
    Then el sistema deniega el acceso

  Scenario: Permiso general del Proveedor no es suficiente para recursos ajenos
    Given un usuario con rol "Proveedor" tiene permiso general para una acción
    When intenta ejecutar esa acción sobre recursos de otro proveedor
    Then el sistema deniega el acceso

  Scenario: Denegación de acceso a funcionalidades no autorizadas
    Given un usuario con rol definido ha iniciado sesión
    When intenta acceder a una funcionalidad no autorizada para su rol
    Then el sistema deniega el acceso

  Scenario Outline: Bloqueo de operación protegida sin sesión válida
    Given un usuario cuenta con una sesión "<estado de sesión>"
    When intenta ejecutar una operación protegida
    Then el sistema deniega el acceso
    And solicita una nueva autenticación

    Examples:
      | estado de sesión   |
      | expirada           |
      | revocada           |
      | sin iniciar sesión |
