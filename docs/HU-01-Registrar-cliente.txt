Feature: HU-01 Registrar cliente
  Como cliente de la plataforma
  Quiero registrarme proporcionando mis datos personales
  Para crear una cuenta que me permita acceder de forma segura a los servicios de reserva

  Scenario: Registro exitoso con datos válidos
    Given un visitante no registrado está en el registro de cliente
    When completa todos los datos con información válida y envía la solicitud
    Then el sistema crea la cuenta exitosamente
    And le asigna el rol "Cliente" por defecto

  Scenario: Acceso del usuario tras el registro
    Given un visitante se registró exitosamente
    When el sistema termina el registro
    Then el usuario queda autenticado o es llevado a la pantalla de inicio de sesión

  Scenario: Protección de la contraseña y los datos sensibles
    Given un visitante se registró exitosamente con datos válidos
    When su cuenta queda creada en la plataforma
    Then su contraseña y demás datos sensibles quedan guardados de forma segura
    And nadie, ni el equipo desarrollador ni quien administra la plataforma, puede verlos de forma legible

  Scenario: Registro con correo ya existente
    Given ya existe una cuenta registrada con el correo "cliente@ejemplo.com"
    When un visitante intenta registrarse con el correo "cliente@ejemplo.com"
    Then el sistema rechaza la solicitud y no crea una cuenta duplicada
    And muestra un mensaje indicando que el correo ya está en uso

  Scenario: Registro con formato de correo inválido
    Given un visitante está en el registro de cliente
    When ingresa un correo con formato inválido, por ejemplo "usuario@@dominio", y envía la solicitud
    Then el sistema rechaza la solicitud y no crea ninguna cuenta
    And muestra un mensaje de error indicando que el formato del correo no es válido

  Scenario Outline: Número de celular con formato inválido
    Given un visitante tiene nombre, correo y contraseña válidos
    When envía la solicitud con el celular "<celular>"
    Then el sistema rechaza la solicitud y no crea ninguna cuenta
    And muestra un mensaje de error indicando que el número de celular no es válido

    Examples:
      | celular    |
      | abcde12345 |
      | 12345      |
      | 123        |
      | 1234567890 |

  Scenario: Registro con número de celular ya registrado en otra cuenta
    Given ya existe una cuenta registrada con el número de celular "3001234567"
    When un visitante intenta registrarse con el celular "3001234567"
    Then el sistema rechaza la solicitud y no crea una cuenta duplicada
    And muestra un mensaje indicando que el número de celular ya está en uso

  Scenario Outline: Contraseña válida con un carácter especial permitido
    Given un visitante tiene nombre, correo y celular válidos
    When envía una contraseña con mayúscula, minúscula, mínimo 8 caracteres y el carácter especial "<carácter especial>"
    Then el sistema crea la cuenta exitosamente

    Examples:
      | carácter especial |
      | ¡                 |
      | *                 |
      | +                 |
      | °                 |

  Scenario Outline: Contraseña que no cumple la política de seguridad
    Given un visitante tiene nombre, correo y celular válidos
    When envía una contraseña que incumple el requisito "<requisito>"
    Then el sistema rechaza la solicitud y no crea ninguna cuenta
    And muestra un mensaje indicando el requisito de seguridad no cumplido

    Examples:
      | requisito                          |
      | contener al menos una mayúscula    |
      | contener al menos una minúscula    |
      | tener mínimo 8 caracteres          |
      | contener al menos un carácter especial |

  Scenario Outline: Campo obligatorio faltante
    Given un visitante está en el registro de cliente
    When deja vacío el campo "<campo>" y envía la solicitud
    Then el sistema rechaza la solicitud y no crea ninguna cuenta
    And muestra un mensaje de error específico para el campo "<campo>"

    Examples:
      | campo              |
      | nombre completo    |
      | correo electrónico |
      | número de celular  |
      | contraseña         |

  Scenario: Bloqueo temporal por múltiples intentos de registro
    Given un mismo origen realizó 5 intentos de registro en poco tiempo
    When intenta registrarse nuevamente
    Then el sistema bloquea temporalmente nuevas solicitudes desde ese origen
