Feature: HU-04 Cerrar sesión
  Como usuario autenticado
  Quiero cerrar mi sesión
  Para impedir que otras personas puedan utilizar mi cuenta sin autorización

  Scenario: Cierre de sesión exitoso
    Given un usuario tiene una sesión activa y autenticada
    When ejecuta la acción de cerrar sesión
    Then la sesión queda invalidada en todos los dispositivos asociados

  Scenario: Renovación automática desactivada tras cerrar sesión
    Given un usuario cerró su sesión exitosamente
    When el sistema termina el cierre de sesión
    Then la renovación automática de la sesión queda desactivada

  Scenario: Expiración automática de sesión
    Given una sesión superó su tiempo de vida máximo (1 hora)
    When el usuario intenta usar esa sesión
    Then el sistema la trata como revocada y deniega el acceso a operaciones protegidas

  Scenario: Error al cerrar sesión
    Given un usuario tiene una sesión activa
    When ejecuta la acción de cerrar sesión y ocurre un error, por ejemplo una falla de conexión con el servidor
    Then el sistema maneja el error apropiadamente

  Scenario Outline: Informe del resultado del cierre de sesión
    Given un usuario ejecuta la acción de cerrar sesión
    When el cierre de sesión resulta "<resultado>"
    Then el sistema informa al usuario que el cierre de sesión fue "<mensaje>"

    Examples:
      | resultado | mensaje  |
      | exitoso   | exitoso  |
      | fallido   | fallido  |
